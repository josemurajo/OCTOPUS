1 · Descarga el instalador

Contiene la clave del equipo: llévalo por un medio de confianza (USB, carpeta compartida privada) y bórralo al terminar. No lo envíes por correo. Cada descarga crea una clave nueva y la anterior deja de valer.

2 · Instálalo en el equipo

{% if sys.os_family == 'windows' %}
  1. Descomprime el .zip en el equipo {{ sys.hostname }}.
  2. Clic derecho en INSTALAR.bat → «Ejecutar como administrador».
  3. Espera al mensaje verde «OCTOPUS instalado» (2-5 minutos; necesita Internet la primera vez).
{% elif sys.os_family == 'macos' %}
  1. Copia el .zip al Mac {{ sys.hostname }} y ábrelo.
  2. Clic derecho en INSTALAR.command → «Abrir», y escribe la contraseña de administrador.
  3. Cuando lo pida, activa «Acceso total al disco» para OCTOPUS (el instalador abre la ventana).
{% else %}
  1. Copia el .zip al equipo {{ sys.hostname }}.
  2. unzip octopus-{{ sys.hostname }}.zip -d octopus
  3. sudo bash octopus/instalar_linux.sh
{% endif %}

3 · Comprueba
